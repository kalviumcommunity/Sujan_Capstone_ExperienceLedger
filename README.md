# Experience Ledger

## Project Idea

Experience Ledger is a centralized web platform where students log internships and academic projects in a structured, consistent format. Faculty mentors verify each entry through a review workflow, converting self-reported claims into institutionally validated records. Placement cell officers and department administrators get analytics dashboards showing skill trends, placement readiness, and cohort-level insights, replacing today's informal tracking across resumes, spreadsheets, and chat groups.
